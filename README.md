LeetCode Metrics Dashboard

A simple and interactive web app to track LeetCode user statistics in real time.
It fetches data using an API and displays it in a clean dashboard with charts and progress indicators.

 Features

Search any LeetCode username

 Displays solved problems (Easy, Medium, Hard)

 Shows ranking and total solved count

 Visual progress indicators / pie charts

 Real-time data fetching using API

 Error handling for invalid users

 Clean and responsive UI
